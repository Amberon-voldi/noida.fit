# User Journey Maps & Interaction Flows — NOIDA.FIT

This document details the primary user flows for NOIDA.FIT, illustrating step-by-step how users navigate from online discovery to real-world physical participation.

---

## 1. Primary V1 Flows

### Flow 1: Weekend Event Discovery to Real-World Arrival
*Persona: Kabir, a 28-year-old software engineer living in Sector 137 who wants to run on Saturday morning.*

```text
[Step 1: Acquisition]
User sees an Instagram Story or receives a WhatsApp link -> Lands on noida.fit
   │
[Step 2: Homepage Engagement]
User sees hero headline: "Find your people. Show up. Move together."
Clicks primary CTA: [Explore Noida Fitness]
   │
[Step 3: Discovery & Filter]
On /discover, user selects:
- Activity: [Running]
- Date: [This Weekend]
- Sector: [Sector 137 / Expressway]
   │
[Step 4: Event Evaluation]
Clicks on "Saturday Sunrise Expressway Long Run (10K & 16K)" hosted by UPRUN.
Reads key facts: 05:45 AM start, meeting at Advant Navis Gate 2, all paces welcome.
   │
[Step 5: RSVP & Commitment]
Clicks [RSVP / I'm Attending].
Enters Name and Phone number.
Clicks [Add to Google Calendar] -> Event saved to mobile calendar.
Taps [Join Saturday WhatsApp Chat] to coordinate parking.
   │
[Step 6: Real-World Participation]
Saturday 05:45 AM: Shows up at Advant Navis Gate 2, runs 10K, drinks chai with the group.
```

---

### Flow 2: Finding a Permanent Community
*Persona: Priya, a 34-year-old marketer who recently relocated to Sector 50 and wants a weekday running club.*

```text
[Step 1: Direct Entry]
User opens noida.fit/communities
   │
[Step 2: Directory Browsing]
Filters by "Running" and scans verified community cards.
Finds "Noida Runners Club (NRC)" based at Noida Stadium (Sector 21A).
   │
[Step 3: Evaluating the Community Hub]
Views /community/noida-runners-club.
Checks the Weekly Recurring Schedule table:
- Tuesday 05:45 AM: Track intervals
- Thursday 05:45 AM: Tempo run
- Sunday 06:00 AM: Long run
Inspects pace groups: notices a dedicated 6:30/km conversational pace group.
   │
[Step 4: Joining]
Clicks [Join Community].
Modal presents official invite link: [Join NRC WhatsApp Community].
User is now directly connected to the club leaders.
```

---

### Flow 3: Community Leader Submitting Their Club
*Persona: Arjun, founder of a weekend calisthenics crew meeting at Meghdootam Park.*

```text
[Step 1: Entry]
Arjun visits noida.fit/for-organizers
   │
[Step 2: Reviewing Standards]
Reads the organizer criteria: Must have recurring schedule, welcoming to beginners, free or transparently priced.
   │
[Step 3: Submission Intake]
Fills out the streamlined form:
- Club Name: "Noida Calisthenics Crew"
- Primary Sector / Park: Meghdootam Park (Sector 50)
- Meeting Days & Times: Sunday 7:00 AM
- Captain Name & Instagram / WhatsApp contact
- Short description & club photo
   │
[Step 4: Verification & Listing]
NOIDA.FIT team verifies details via WhatsApp/Instagram within 24 hours.
Community page published live at noida.fit/community/noida-calisthenics-crew.
```
